    WireFrame EDA User Guide

    WireFrame EDA is a lightweight EDA environment combining:

    • Schematic editor for circuit design.
    • PCB editor for layout, routing and manufacturing data.
    • Symbol & footprint wizards for quickly generating libraries.
    • 3D viewer for PCB visualization.
    • Project management with multi‑sheet schematics and multiple PCBs.

    Typical Workflow

    1. Create or open a project
    2. Use the main menu to create a .prjxml project.

    3. Add or open schematic (.schxml) and PCB (.pcbxml) documents.

    4. Design the schematic

    5. Place components from symbol libraries.
    6. Wire nets, add labels, power symbols and graphic annotations.

    7. Use the properties panel to edit component attributes and page settings.

    8. Generate / sync PCB

    9. Convert the schematic into a PCB document.

    10. Place footprints, assign footprints to symbols if needed.

    11. Route the PCB

    12. Route traces with 45° paths, place vias and mechanical holes.

    13. Manage layers, copper pours/zones and DRC/DFM checks.

    14. Finalize & export

    15. Run DFM checks.
    16. Generate Gerber, drill files and BOM.
    17. Optionally inspect the board in 3D.

    Who is this for?

    • Users who are familiar with basic EDA concepts (nets, footprints, layers) and want a focused, script‑free tool.
    • Hobbyists and professionals who prefer an ImGui‑style, keyboard‑friendly desktop UI.

    If you are just starting, continue to Getting Started.
